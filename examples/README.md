# Exemplos reproduzíveis

Área reservada a exemplos distribuíveis do EnziTAG Optima.

Cada exemplo deverá informar objetivo, origem dos dados, fatores ou tratamentos, respostas, configurações da análise e resultados esperados. Utilizar dados sintéticos ou dados autorizados para publicação.

Ainda não há exemplos de execução nesta pasta. Os exemplos pequenos usados para aprendizagem serão ligados à [documentação](../docs/aprendizado/README.md) e à [validação](../validation/README.md).
