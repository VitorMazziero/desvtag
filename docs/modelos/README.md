# Modelos de documentos

**Estado:** vigente · **Atualizado em:** 2026-11-01

Copiar o modelo, renomear conforme a [nomenclatura](../convencoes/nomenclatura.md) e substituir os campos entre `<>`. Seções que não se aplicam recebem "Não se aplica" com o motivo, em vez de serem apagadas.

| Modelo | Uso | Destino e nome |
|---|---|---|
| [Plano de execução](plano-execucao.md) | Nova etapa de execução | `docs/planos-execucao/planejados/et<nn>-<slug>.md` |
| [Decisão técnica](decisao-tecnica.md) | Escolha técnica com alternativas | `docs/decisoes-tecnicas/dt-<nnnn>-<slug>.md` |
| [Ficha de módulo](ficha-modulo.md) | Documentação de manutenção de um módulo | `docs/modulos/<id>-<slug>.md` |
| [Especificação de método](especificacao-metodo.md) | Fundamentação científica de um procedimento | `docs/metodos/<slug>.md` |
| [Caso de validação](caso-validacao.md) | README de um caso de referência | `validation/cases/<method_id>/<nnn>-<slug>/README.md` |
