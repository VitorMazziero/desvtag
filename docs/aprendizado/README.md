# Aprendizagem por módulo

Cada módulo deverá explicar:

1. A pergunta que será respondida e as fórmulas necessárias.
2. Um exemplo pequeno, com etapas de cálculo acompanháveis.
3. Os conceitos de Rust utilizados na implementação.
4. As entradas recebidas e os resultados entregues aos outros módulos.
5. A apresentação desses resultados no aplicativo.
6. A comparação com referências independentes.

Este é o material detalhado de estudo. As explicações na interface do produto serão curtas, conforme a concepção aceita.

O primeiro módulo ainda será implementado. Ver a [sequência de aprendizagem](../../plans/ARQUITETURA_E_APRENDIZADO.md).
