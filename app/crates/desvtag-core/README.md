# desvtag-core

Núcleo científico em Rust do DesvTAG.

Responsabilidades previstas: estruturas dos dados experimentais, validação, estatística descritiva, fundamentos numéricos, distribuições, modelos, inferência, comparações, letras, planejamentos, predição e otimização.

O núcleo deve funcionar independentemente de interface, conta online e acesso a arquivos. As rotinas serão implementadas e documentadas progressivamente, preservando o raciocínio e as etapas intermediárias dos cálculos.

Na ET01 existem apenas as estruturas iniciais (identificadores, tipo de fator, diagnósticos, registro de métodos vazio, proveniência); nenhum método científico. O detalhamento está no [mapa de módulos](../../../docs/arquitetura/mapa-modulos.md); a arquitetura, na [visão geral](../../../docs/arquitetura/visao-geral.md).
